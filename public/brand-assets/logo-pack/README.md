# Crystal Clear Academy — Official Logo Pack Deliverables

This directory contains the complete 6 official logo file format deliverables for Crystal Clear Academy (CCA) print, web, and social media production use:

## Included Formats & Files

1. **Vector Master Format** (`CCA-Master-Logo.svg` / `.ai`)
   - High-resolution SVG vector containing both navy brand path and gold gradient accent.
   - Ideal for high-dpi print materials, signboards, large banners, and vector editing software (Adobe Illustrator, Figma, Inkscape).

2. **PNG Dark Background Variant** (`CCA-Logo-Dark.png` / `CCA-Logo-White.svg`)
   - Monochromatic white + gold accent vectors optimized for dark navy, charcoal, or photo background overlays.

3. **PNG Light Background Variant** (`CCA-Logo-Light.png` / `CCA-Master-Logo.svg`)
   - Deep Navy (`#1F4E79`) + Gold (`#C6A75E`) contrast logo tuned for clean white or light gray stationery and web pages.

4. **Mark-Only Icon Variant** (`CCA-Logo-MarkOnly.svg`)
   - Standalone golden emblem mark without text, tailored for app icons, favicons, social media profile avatars, and badges.

5. **Flat Gold Variant** (`CCA-Logo-FlatGold.svg`)
   - Solid gold tone (`#C6A75E` & `#D2BE98`) without heavy gradients for single-color foil printing, embroidery, and engraved plaques.

6. **Monochromatic White Variant** (`CCA-Logo-White.svg`)
   - Pure white line work for dark social media posts and video watermarks.
